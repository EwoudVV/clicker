# Clicker

A 2-switch wireless macropad.

This project is 2 pcbs. One is a reciever, which you plug into your computer, and the other is a remote, or transmitter, with the buttons. The reciever acts like a keyboard, so no drivers need to be installed on the computer.

Reciever pcb:
 - 2 layer
 - esp32
 - plugs directly into a usb-a port, no cable
 - an led that blinks when something is being sent

Remote pcb:
 - same esp32
 - small battery
 - 2 switches (likely smd)
 - 2 layer
 - probably 2 side assembly
 - usb-c port for charging

Roadmap:

 - Find specific esp32s and switches
 - build schematic
 - find specific part numbers and footprints for everything
 - route the pcbs
 - finish up, make production files
 - submit!
