# Clicker

A 2-switch wireless macropad.

This project is 2 pcbs. One is a reciever, which you plug into your computer, and the other is a remote, or transmitter, with the buttons. The reciever acts like a keyboard, so no drivers need to be installed on the computer.

Reciever pcb:
 - 2 layer
 - esp32 s3
 - has a usb-c port for computer
 - an led that blinks when something is being sent

Remote pcb:
 - same esp32 s3
 - small battery
 - 2 switches (khalih choc v1 smd)
 - 2 layer
 - 2 side assembly
 - usb-c port for charging
